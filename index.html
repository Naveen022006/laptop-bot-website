How it works

Discord is the remote. Your laptop does the work.

A small Python program on your laptop signs in as your own Discord bot. When you type a command, it runs it locally and replies with the result.

You type a command

From Discord on your phone, tablet or any other computer — e.g. !screenshot.

Discord delivers it

The bot keeps an outbound connection to Discord, so there’s no port forwarding or public IP needed.

Your laptop responds

The bot checks you’re on the allow-list, runs the action and posts the result back in the channel.

What it can do

Eight modules. One chat window.

Each module is a small Python file in the bot, so it’s easy to read, tweak or extend.

Screenshots

See exactly what’s on your screen right now.

  • !screenshot

Webcam

Snap a photo from the built-in camera.

  • !webcam

Live streaming

Watch your screen live in Discord or in a phone browser on your Wi-Fi.

  • !stream_start
  • !stream_web_start

System control

Open apps, search Chrome, set volume, lock or shut down.

  • !lock
  • !vol_set
  • !open

Apple Music

Search and play songs, pause, skip and go back.

  • !play
  • !next_song

Text to speech

Make your laptop say anything out loud.

  • !speak

File download

Pull any file up to 25 MB straight into Discord.

  • !download

System info

OS, CPU, memory and disk usage at a glance.

  • !sysinfo

Private by design

Your bot. Your token. Your rules.

There’s no shared server and no account to sign up for. You create your own Discord bot and run it on your own machine.

  • Allow-listed users onlyCommands from anyone not listed in AUTHORIZED_USERS are ignored.
  • Secrets stay localYour bot token lives in a .env file on your laptop and is never sent anywhere except Discord.
  • Read every lineThe full source is on GitHub, so you can audit exactly what each command does.
.env 
# Keep this file private — never commit it
DISCORD_TOKEN=your_bot_token_here
AUTHORIZED_USERS=123456789012345678

# Several people? Separate IDs with commas
# AUTHORIZED_USERS=1234…,5678…
Quick start

Up and running in about ten minutes.

All you need is Python 3.8+, Git and a Discord account.

  1. Create a Discord bot

    Make an application in the Discord Developer Portal and copy its token.

  2. Clone & install

    Download the code and install the Python requirements.

  3. Add your .env

    Paste your token and your own Discord user ID.

  4. Run it

    Start bot.py and send !screenshot to test.

terminal 
$ git clone https://github.com/Naveen022006/laptop-control-application.git
$ cd laptop-control-application
$ pip install -r requirements.txt
$ python bot.py
Logged in as Laptop Bot — ready to receive commands.
