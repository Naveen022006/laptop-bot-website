Setup guide

Create your own Discord bot, run it on your laptop, and control it from anywhere. No servers, no sign-ups.

00

Before you start

Make sure you have these ready:

  • Python 3.8 or newer
  • Git (or download the ZIP)
  • A Discord account
  • A Discord server you manage
  • Windows, macOS or Linux
  • About 10 minutes
01

Create your Discord bot

  1. Open the Discord Developer Portal and click New Application.
  2. Give it a name, e.g. “Laptop Control Bot”.
  3. In the Bot tab, click Reset Token and copy the token somewhere safe.
  4. On the same page, turn on Message Content Intent so the bot can read your commands.
  5. Go to OAuth2 → URL Generator, tick the bot scope and the permissions you want (at minimum: View Channels, Send Messages, Attach Files, Embed Links).
  6. Open the generated URL and add the bot to your server.

Treat the token like a password. Anyone who has it can control your bot — and therefore your laptop. If it leaks, reset it in the Developer Portal immediately.

02

Download the code

Clone the repository, or download the ZIP from GitHub and extract it.

terminal 
$ git clone https://github.com/Naveen022006/laptop-control-application.git
$ cd laptop-control-application
03

Create a virtual environment

This keeps the bot’s packages separate from the rest of your system.

PowerShell 
$ python -m venv venv
$ .\venv\Scripts\activate
terminal 
$ python3 -m venv venv
$ source venv/bin/activate

You should now see (venv) at the start of your prompt.

04

Install dependencies

With the virtual environment active, install everything the bot needs:

terminal 
$ pip install -r requirements.txt
05

Add your .env file

Create a file called .env in the project folder:

.env 
DISCORD_TOKEN=your_bot_token_here
AUTHORIZED_USERS=your_discord_user_id

Finding your Discord user ID

  1. In Discord, open Settings → Advanced and enable Developer Mode.
  2. Right-click your name (long-press on mobile) and choose Copy User ID.

To let several people use the bot, separate the IDs with commas: AUTHORIZED_USERS=1234…,5678…

Never commit .env to Git. Make sure it’s listed in .gitignore.

06

Start the bot

With the virtual environment active:

terminal 
$ python bot.py
Logged in as Laptop Bot (123456789)
------
Bot is ready to receive commands.

Keep this window open — the bot only works while it’s running.

✓

Say hello

In your Discord server, send:

Discord 
$ !screenshot

That’s it. If a screenshot comes back, you’re all set. Try !sysinfo or !speak "Hello" next, or browse the full command list.

Troubleshooting

The bot is online but ignores my commands
  • Check your user ID is in AUTHORIZED_USERS — no spaces, comma-separated.
  • Make sure Message Content Intent is enabled in the Developer Portal.
  • Confirm the bot can view and send messages in that channel.
The bot never comes online
  • Double-check DISCORD_TOKEN in .env (reset it if unsure).
  • Look at the terminal for an error message when you run python bot.py.
ImportError / ModuleNotFoundError
  • Activate the virtual environment first (see step 03).
  • Re-run pip install -r requirements.txt.
  • Check your Python version with python --version (3.8+).
A command runs but returns an error
  • Read the error in the terminal running the bot.
  • Some commands need extra software — Chrome for !chrome_search, Apple Music for !play.
  • Webcam and screenshot commands may need OS permission (camera / screen recording on macOS).

Start automatically with Windows

The repository includes a helper that registers the bot to launch when you sign in:

PowerShell
