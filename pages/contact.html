FAQ

Common questions

Is the bot free to use?

Yes. It’s completely free and open source — use it, change it and share your improvements.

Is my laptop safe?

Only Discord users whose IDs you put in AUTHORIZED_USERS can run commands, and your bot token never leaves your machine except to talk to Discord. The bot can do powerful things (shut down, send files), so keep your token secret and only authorize people you trust.

Do I need to keep a window open?

Yes — the bot only responds while python bot.py is running. On Windows you can use setup_startup.py to start it automatically when you sign in.

Which operating systems are supported?

Windows, macOS and Linux. A few features are Windows-first (like Chrome detection and startup registration), but most commands work everywhere.

Can I add my own commands?

Absolutely. Each feature lives in its own Python file in the commands/ folder — copy one as a starting point.

How do I get updates?

Watch or star the GitHub repository and pull the latest changes, or download a new release.
