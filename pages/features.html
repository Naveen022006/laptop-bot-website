Command reference

Every command the bot understands. Type them in any channel the bot can read. Arguments in <angle brackets> are required, ones in [square brackets] are optional.

Audio & voice

audio.py
!speak <message>

Make the laptop speak a message out loud using the system’s native text-to-speech.

Example: !speak "Hello there!"

System control

control.py
!open_chrome

Open Google Chrome on the laptop.

!chrome_search <search terms>

Open Chrome and search Google directly.

Example: !chrome_search weather in chennai
!open <app_name>

Try to open an application by name.

Example: !open notepad
!lock

Lock the computer workstation.

!shutdown

Start a system shutdown (10 second delay by default).

Use with care
!vol_up [amount]

Raise the system volume by 1–50 (default 10).

Example: !vol_up 5
!vol_down [amount]

Lower the system volume by 1–50 (default 10).

Example: !vol_down 15
!vol_set <level>

Set the master volume to an exact percentage (0–100).

Example: !vol_set 50
!mute

Toggle system audio mute on or off.

File management

files.py
!download <path>

Send a file from the laptop to Discord (25 MB limit).

Example: !download C:\Users\YourName\Documents\file.txt

Apple Music

music.py
!play <song name>

Open Apple Music, search for the song and play it.

Example: !play Blinding Lights
!pause_music

Pause or resume the current song.

!stop_music

Stop the current song and rewind to the start.

!next_song

Skip to the next track.

!prev_song

Go back to the previous track.

Screenshots

screenshot.py
!screenshot

Capture the primary display and upload it to Discord.

Live streaming

stream.py
!stream_start

Start a live view that updates one Discord message with a fresh screenshot every second.

!stream_stop

Stop the Discord live view.

!stream_web_start

Start a web stream server you can open in any phone or tablet browser on the same network.

Mobile-friendly
!stream_web_stop

Stop the web stream server.

System information

systeminfo.py
!sysinfo

Show OS details plus CPU, memory and disk usage.

Webcam

webcam.py
!webcam

Take a photo with the default webcam and upload it to Discord.

Good to know

Tips & limits

  • Authorized users onlyOnly Discord IDs listed in AUTHORIZED_USERS can run commands.
  • Quote longer textWrap messages with spaces in quotes: !speak "Hello world".
  • File size limit!download sends files up to 25 MB — servers without boosts may allow less.
  • Same Wi-Fi for web stream!stream_web_start is reachable from devices on your local network.
  • Some apps requiredChrome and Apple Music commands need those apps installed on the laptop.
  • PermissionsThe bot needs permission to read and send messages and attach files in your channel.
